# INYOURS 내부 관제 대시보드

프로젝트 33개 · 지원사업 37건의 진행 상황을 한 화면에서 추적하는 **내부용** 사이트.

## 쓰는 법

- `index.html` 을 더블클릭하면 바로 열립니다. 서버·설치 필요 없음.
- 상태를 바꾸거나 체크하면 **이 브라우저에** 자동 저장됩니다.
- 다른 기기에서 이어서 보려면 → `내보내기`(JSON 저장) → 그쪽에서 `불러오기`.

## 데이터 수정

`index.html` 안의 `const P = [...]`(프로젝트), `const F = [...]`(지원사업)만 고치면 됩니다.
빌드 과정 없음 — 저장하고 새로고침하면 끝.
